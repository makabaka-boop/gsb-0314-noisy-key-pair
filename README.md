# 二歧检索表编辑器（Lit + TypeScript）

交互式二歧分类检索表（dichotomous key）编辑器。由 Compose 的 **key 页面**（`#/key`，默认页）
呈现，Vitest 对拍树形求解。

## 规则

- 输入 **3–16 个唯一 ASCII 物种 id**、**2–16 个唯一 ASCII 二值特征 id**，每行一个；
  矩阵为完整的 **物种 × 特征** 0/1 矩阵，点击单元格切换。
- 若两个（或多个）物种的**特征向量完全相同**，返回
  `INDISTINGUISHABLE` 及 **id 字节序最小的物种对**，**不伪造识别树**。
- 其余情况，对当前候选物种集合只选择**能真正分裂它**的特征，生成最优决策树：
  1. 最小化**最坏提问数**（树高）；
  2. 并列时最小化**所有物种路径长度之和**；
  3. 仍并列时按**特征 id 字节序**（逐字节字典序）裁决。
- **编辑矩阵后旧树立即失效**（页面提示 stale，需重新生成）。
- 用户可沿 **是/否** 分支实际识别样本，显示当前候选物种，可**撤销 / 回到任意一问 / 重新开始**。
- 勾选“一次观察错误”后，识别允许整个回答序列里最多有一次是/否回答与真实物种矩阵不符。此时同一特征可以重复提问；每条可发生的回答路径都必须收敛到唯一物种。该模式最多支持 6 个物种、6 个特征。先最小化所有可能回答路径的最坏提问数，再最小化这些路径的总提问数，最后按特征 id 字节序裁决。候选列表应保留与迄今回答至多相差一次的物种；回溯应恢复对应候选。

## 求解器

`src/solver/key.ts` 为纯逻辑模块：

- `parseSpecies` / `parseFeatures`：ASCII、数量、唯一性校验；
- `validateMatrix`：完整矩阵维度与取值校验；
- `findIndistinguishablePair`：最小 id 同向量物种对；
- `buildKey`：返回 `INDISTINGUISHABLE` 或最优树（位掩码记忆化 DP）。

DP 状态为候选物种集合位掩码；在每个状态枚举所有非平凡分裂
（`yesMask`、`noMask` 均非空），按 `(最坏深度, 总深度, 特征字节序)` 取最小。

### 允许一次观察错误（`allowOneMistake`）

DP 状态升级为两个物种集合的位掩码：

- `S0`：与迄今全部回答相符（0 次不符）；
- `S1`：与迄今回答恰好一处不符（容错额度已用，后续必须全相符）。

回答“是”时 `yes0 = S0∩has`、`yes1 = (S1∩has) ∪ (S0∖has)`（S0 中不具备
该特征者用掉额度进入 S1，S1 中仍不具备者出现第二次不符被淘汰）；
回答“否”对称。`|S0∪S1| ≤ 1` 时出叶。同一特征允许重复提问；对当前候选
取值恒定（无分裂作用）的特征跳过——它既不提供信息，也是唯一的递归自环
来源。指标只统计**可发生**的回答路径（某条叶路径至少对一个物种不符数
≤1），按 `(最坏提问数, 路径提问数之和, 特征字节序)` 取最小。状态编码为
`(S1 << n) | S0`，状态数不超过 3^n，故该模式限定物种、特征各不超过 6 个。

识别面板的候选列表按整条回答序列统计不符次数（重复提问逐次计数，不用
特征→单值的 Map 覆盖）；回溯或改选后，候选与叶结论完全由当前回答记录
从根重放得出，始终与记录一致。

## 测试

`tests/key.test.ts` 含一个**独立穷举树形求解器**（显式枚举所有合法决策树，
不共享 DP 的状态与比较逻辑），并沿每个物种的向量实际走树独立统计深度：

- 3×2（64）、3×3（512）、4×3（4096）、4×4（65536）全部矩阵穷举对拍，
  核对最坏深度、总深度与并列后的完整树结构；
- INDISTINGUISHABLE 最小对（多等价组、非下标顺序命名）；
- 字节序裁决（如 `'10' < '2'`）、最坏深度优先于总深度、常数列忽略、
  重命名物种不改变结构；16×16 冒烟（最坏 4、总和 64）。

容错模式另有**独立参考 DP**（不同的状态键编码与候选收集逻辑），对 4×2、
3×3、4×3 全部互异矩阵穷举对拍完整树结构；`verifyMistakeTree` 还独立校验：
枚举每条根→叶路径，核对“至多一处不符即可到达的物种恰好唯一且叶标签
正确”，再模拟每物种“无错 / 恰好在第 j 问答错”的实际行走（后续提问以走到
的节点为准，因特征会重复提问），独立汇总最坏提问数与路径提问数之和。
`tests/key-editor.test.ts` 覆盖容错模式 UI：指标切换、首问答错后真实物种
不被淘汰、重复核对识别成功、回溯改选后候选与叶结论同步、关闭选项恢复
普通树。

```bash
npm install

npm run build   # tsc --noEmit + vite build

```
